# Minitask 1

membuat folder baru dengan nama lagu_lagu, 

```shell
mkdir lagu_lagu
```

jika nama folder yang akan dibuat memiliki spasi
maka harus menggunakan " untuk membungkus nama nya agar tidak terpotong contoh
kalau hanya 

```shell
mkdir lagu lagu
```
folder yang dihasilkan hanya lagu saja bukan "lagu lagu"
atau bisa juga membuat nama yang disambun dengan underscore atau strip

setelah folder berhasil dibuat kemduian masuk kedalam folder lagu_lagu
```shell
cd lagu_lagu
```

kemudian membuat file dengan perintah "ni", perintah ni ini akan membuat file kosong
dengan ukuran 0 byte, jika nama file nya memiliki spasi maka nama file harus dibungkus menggunakan tanda " agar tidak terpotong nama file yang dihaislkan
atau dapat menggunakan sambungan seperti underscore
```shell
ni "madison beer - reckless.mp3"
ni "madison beer - bittersweet.mp3"
ni "bruno mars - die with a smile.m3"
ni "bruno mars - talking to the moon.mp3"
ni "porter robsinon - get your wish.mp3"
ni "porter robinson - shelter.mp3"
ni "alan walker - faded.mp3"
ni "alan walker - sing me to sleep.mp3"
ni "hindia - wajahmu ku ingat selalu.mp3"
ni "hindia - secukupnya.mp3"
```
